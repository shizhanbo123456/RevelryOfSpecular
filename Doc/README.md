## 使用规则（避免再出现重复与遗漏）

1. **一个主题只在一个文件里写**，其它文件用「见《0X-…》」指针，不复制内容。
2. 新增/修改技能或 Buff → 只改 `03`；新增特效资产 → 只改 `04`；实现方式变化 → 只改 `02`。
3. 文档之间不重复描述同一个表格；确需摘要时，摘要里必须带指针。
4. 数值若从代码常量读取（技能 CD / 倍率 / 半径），文档只写“见代码”，不抄数值，避免两处不一致。
