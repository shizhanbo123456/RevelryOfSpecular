实现说明

指令枚举 GmEnum：42 条，含 GmLabel（菜单路径 组-子-项）与 GmStatus（启用时机：Offline / Lobby / Battle 三位，缺省 Battle；42 条逐条标注）
布局表 Layout.layoutStyle：每条指令一串 LayoutInfo（7 种控件），Layout.GetLayout(枚举)
GM 下拉枚举：GmEntityType / GmSettleType / GmFilterType / GmStatue / GmCharacter
协议结构：CSGm(type,int1,int2,float1,float2,float3) / SCGm(type,int1,float1)，type 走 int 序列化
客户端面板逻辑 UI/Logic/GmPanel.cs：GmLabel 路径生成两级菜单 + GetLayout 渲染参数行 + 按钮回调（收集控件值→填 CSGm→发包）
行→CSGm 组包 + 发包：NetworkManager.SendGm → [Rpc] ServerReceiveGmLocal → BattleManager.ExecuteGm
面板入口：1 秒内连按 3 次 V 开启、Backspace 关闭（UIManager 创建并每帧驱动 GmPanel；编辑输入框时不响应）
本地执行项（纯客户端指令，不联网也生效）：画面（地形显示半径 / 显隐地形 / 雾气）、存档（玩家经验± / 等级± / 角色等级）、其它（调试四行数据、性能-模型网格面数、结算界面演示、本地延迟）——共 12 条，均在 GmPanel.RunLocal 内实现；敌方对话开关同样是本地实现，但只有联网时才有意义，故标注为 Lobby | Battle
面板显示按 GmStatus 过滤（GmPanel.Visible）：读枚举项 [GmStatus] 与当前相位（未联网 = Offline / 已联网未开战 = Lobby / 对局中 = Battle）按位相与，未标注按缺省 Battle；「被动技能启用」的组队期限制由标注（Lobby）表达
结算界面为独立子界面 SettlementView（UIManager 持有，挂 GRoot、不挂页面）
敌方对话开关：ChatPlugin.ShowEnemyDialog，开启后放行敌方阵营频道消息（不存历史，仅影响之后收到的消息）
服务器端 GM 执行体 GameController/BattleManagerGm.cs（partial BattleManager）：NetworkManager.ServerReceiveGmLocal 一行转发，处理 29 条联网项
服务器 → 客户端回包：SCGm + [Rpc] ClientReceiveGmLocal → ClientEvent.OnGmResult(10311)；性能项回帧率（= EnsInstance.frameRate）与时间（= Time.time）
其它-战斗数据（僵尸数量 / 僵尸刷新等级 / 白天时长 / 夜晚时长）：查询类，走 SCGm 单值回包后刷文本；数据源 = `BattleManager.zombieCount` / `GetZombieSpawnLevel()` / `EnvironmentManager.dayDuration·nightDuration`（后者含白眼伯爵「夜晚延长」被动修正后的值）
开关类指令（飞行 / 无敌 / 极速 / 被动启用）由客户端带目标状态（int1 / int1+int2），按钮标题显示 开/关
被动启用：只在组队期可见（战斗期隐藏）；服务器记录在 gmPassives，开战时经 GmOnBattleStart 并入 ApplyGlobalPassives 一起算
GM 侧向钩子：EntityData.OnDamaged 查 BattleManager.IsGmInvincible；EntitySkillController 提供 GmIgnoreCd / GmForceUseSkill / GmResetAllCd；EntityEffectController 提供 EffectType.GmSpeedUp（Config.gm_speed_multiplier）与 RemoveAll

协议依赖：所有 [Rpc] 由 Ens 生成代码产出，改动协议后必须重新生成，否则调用静默失效（服务端执行体收不到指令）。

备注：
- 「对局-时间」三条单位 = 秒；设置项为「时间(秒)」输入框。
- 「实体-击杀」会污染比分（击杀进攻方角色计入 DefenseKills 并发"被击败"事件）——按用户口径允许。
- 「外挂-无敌」只把伤害判为 0，不免疫击飞与受击动作；「外挂-极速」= GmSpeedUp 移速 buff，复活重建实体会丢（需重开）。
- GmPanel 的 FGUI 细节（GmItem 内容页名 文本/按钮/滑动条/输入框/下拉框、菜单 button_list 的 item 类型）需在正式工程核对。
- 「其它-战斗数据」四项都是服务器权威值（客户端数不到全部僵尸、昼夜时长还被白眼伯爵被动改过），因此走 GM 联网通道、由服务器回包，不在本地读取。
