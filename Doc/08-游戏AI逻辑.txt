人机玩家：

【通用规则】
决策节流 0.15s，与现有实体 AI 一致。
技能冷却由 AI 自己维护：按 skill.csv 的 CD 记「上次释放时刻 + CD」，只尝试技能栏内已就绪的技能；全部未就绪就原地站立，不空放（技能栏见下一节）。
状态分五类：基础（搜索 / 追击）、基础战斗（搜索战斗）、战斗（战斗 / 护送战斗 / 协同进攻战斗 / 集结守卫 / 危险清除战斗）、任务（护送 / 集结 / 协同进攻）、应激（危险躲避 / 危险清除）。
不可打断的只有「战斗」与「危险躲避」；「搜索战斗」虽然也在打，但打的是不还手的珊瑚，随时可以走，是唯一"身处战斗却立即响应"的状态。
所有消息引起的状态转换统一由末尾的「消息响应矩阵」决定，各状态内不再单独罗列。

【AI 技能栏（模拟真人技能栏）】
人机没有客户端，因此在服务器侧维护一份等价结构：
  容量 = 该角色的 weaponSlotCount（直接取实体属性，即 entity.baseAttribute.weaponSlotCount，不走玩家存档）。
  素材 = 服务器已记的持有表（EntitySkillController 的持有技能列表）。
  选栏 = 持有表按「品质从高到低、同品质 id 从大到小」排序，取前 N 个进栏。
  重排时机 = 获得任何新技能（珊瑚掉落、GM 下发、复活继承）后立即重排一次。
  冷却范围 = 只有栏内技能推进冷却；被挤出栏的技能冷却冻结（保留剩余时间），重新入栏时从冻结处继续恢复。
  空手三连 = 不占栏位、始终推进冷却、始终可用，作为栏内技能全不可用时的最后手段。
  新入栏技能 = 从"未就绪"开始按 CD 恢复，不会拿到就能放。
  释放顺序 = 栏内从高到低（索引 0 起）依次试放就绪技能 → 全不可用则试空手三连 → 仍不可用就原地站立（战斗策略里的"全没好就站着"）。

【消息结构】
统一四元组：消息类型 messageId、消息发送者 senderClientId、是否携带目标位置 hasTargetPosition、目标位置 targetPosition。
senderClientId 由服务器按上行连接补齐，客户端不可伪造；服务器按阵营广播，人机只响应本方玩家发的消息，真人不受影响。
**人机忽略自己发出的消息**（自己发"请求护送"给自己没有意义）；判定方式：senderClientId == 自身 clientId 直接丢弃。
消息作废条件：发送者死亡、离线或转为观战 → 该消息不影响任何行为。

【任务锚点（两种形态，行为统一）】
携带位置 → 静态锚点：进入任务状态时把 targetPosition 快照一次，之后不再跟随，发送者之后死亡也不影响任务。
未携带位置 → 动态锚点：锚点就是发送者的当前实体，每帧实时读它的位置，等同「跟着消息发出者走」；发送者死亡/离线 → 任务立即结束，回搜索。
两种形态共用同一套到达判定：与锚点当前距离 ≤ 该状态的到达半径；「返回锚点」类行为（如集结等待）同样按动态锚点实时计算。
转向与移动仍走实体执行层，AI 只下发目的地与朝向点，不直接写速度。

【任务槽（暂存最新任务）】
只有「战斗」与「危险躲避」不可被任务消息打断：战斗、护送战斗、协同进攻战斗、集结守卫、危险清除战斗、危险躲避。
期间收到的任务类消息（护送 / 集结 / 进攻 / 争夺中立）不立即生效，只写入「任务槽」：单槽、后到覆盖、只保留最新一条。
槽内任务在状态真正结束时消费：
  战斗类：目标死亡（脱战）时消费；目标只是跑出攻击距离、转为追击或转回任务态，都不算结束，槽保留。
  危险躲避：躲避自然结束（退够距离或超时）时消费。
  消费时：有槽 → 执行槽内任务；无槽 → 回到该状态原本的返回态。
  消费前必须再校验一次：槽里任务的发送者已死亡/离线、争夺中立时中立单位已不存在 → 任务作废，按"无槽"处理。
解除信号：任何状态都立即生效——清空任务槽、终止当前状态、回搜索。
同一 tick 收到多条任务消息：后到覆盖，取最新一条。
说明：低血被打断时不保留原任务（血量不足以执行任务，回搜索重新开始是预期行为）。

【战斗策略：各战斗态的差异】
差别不在"能不能打"，而在四件事：打谁、在多大范围内打、什么时候放弃、打完回哪。
所有战斗态共用同一套技能释放规则（站定、朝目标，按技能栏从高到低试放就绪技能，栏内全没好再试空手三连，仍没好就原地站立）。

搜索战斗        搜索中遇到珊瑚            当前的珊瑚                无（珊瑚不动）        无（珊瑚不还手）      搜索

设计意图：
护送战斗不能一掉血就跑——被护送对象还在原地，跑了等于放弃职责，所以撤离血线压到 15%。
集结守卫的撤离不是"远离敌人"而是"回集结点"，因为职责是守点不是追杀。
危险清除战斗脱战后回到「危险清除」继续搜寻，而不是直接回搜索——危险点的威胁可能不止一个。
活动范围都以各自的责任点为圆心，出圈即放弃追击，避免被引走导致职责丢失。
搜索战斗的唯一存在理由：珊瑚不还手，打它是"顺手收益"，一有风吹草动就该放弃，所以它是唯一可被立即打断的"战斗"状态。

【群体协同（队友互叫）】
状态机基类额外暴露一个入口：「请求追击某个敌人」，参数是目标实体。
各状态自己决定能否接受这个请求、以及接受后进入哪个状态（例如搜索/搜索战斗接受后进入追击，集结等待接受后进入集结守卫）；
不接受的状态直接忽略，不排队、不打断当前行为。
用途：僵尸的群体呼叫、集结等待喊附近人机一起守点等同类需求共用这一个入口。

【消息 → 锚点对照】
集结(0)：有位置 = 该点；无位置 = 发送者（集结位置随发送者移动）。
进攻(2)：有位置 = 该点；无位置 = 发送者（跟随发送者推进）。
危险警告(3)：有位置 = 该点；无位置 = 发送者当时的位置（快照，不跟随——危险点是"事件发生地"，跟着跑没有意义）。
请求护送(7)：被护送对象恒为发送者本人，位置字段暂不参与。
争夺中立(6)：位置字段不参与，目标 = 场上的中立单位。
解除信号(1)、请求上报各自状况(4)：位置字段不参与。
上报状况(5)：AI 发送时固定携带自身位置，方便玩家定位。

【状态与行为】

搜索（默认状态）
  行为：随机乱跑——在自身周围 R_search（10m）内随机取点移动，到达后随机停顿 1~3s 再取下一个点；不预设目标点，不去"推进某个守护点"。
  索敌（每 tick）：视野内最近的敌对实体，按类别分流——
    若目标是珊瑚 → 搜索战斗（打珊瑚，珊瑚不还手）。
    若目标是角色 / 守护雕像 / 水晶雕像 / 僵尸 → 追击（返回态 = 搜索）。
  防守方额外：守护点告警——每 1s 扫描全部存活的己方守护雕像，任一守护点 15m 内出现敌人 → 立即把追击目标设为「靠近守护点的敌人」（多处告警取离自己最近的那个），进入追击（返回态 = 搜索）。
  优先级：自身视野内的近距离敌人 > 守护点告警 > 打珊瑚 > 继续乱跑。

搜索战斗（珊瑚）
  行为与策略：见「战斗策略」"搜索战斗"行——追上珊瑚打到碎，珊瑚不还手所以没有撤离条件。
  立即打断（本状态特例，不写入任务槽）：
    发现其它敌人（角色/雕像/僵尸）→ 立刻放弃珊瑚，转追击 / 战斗。
    收到任何任务消息 → 立刻放弃珊瑚，按矩阵执行。
  自然转换：珊瑚被打碎 → 搜索；珊瑚消失 → 搜索。

追击（目标、返回态）
  行为：朝目标移动。
  追击上限：返回态是搜索或危险清除时按 40m 判定；返回态是协同进攻时按"与进攻锚点距离 25m"判定，超出即回协同进攻。
  自然转换：目标死亡/消失/超出各自上限 → 返回态；进入攻击距离 → 按返回态决定进入哪个战斗态（搜索 → 战斗，危险清除 → 危险清除战斗，协同进攻 → 协同进攻战斗）。
  说明：护送与集结不经过本状态，各自在自己的活动范围内追打（见护送战斗 / 集结守卫）。

战斗（目标、返回态）
  行为与策略：见「战斗策略」"战斗"行。
  自然转换：目标死亡 → 消费任务槽（有槽执行、无槽回返回态）；目标超出攻击距离且在活动范围内 → 追击（槽保留）；超出活动范围 → 返回态。

前往护送（被护送对象 = 发送者）
  行为：朝被护送对象移动。
  自然转换：进入 5m → 护送；对象死亡/离线 → 搜索；超过 30s 没到达 → 搜索。

护送（被护送对象）
  站位：进入本状态时，一次性在对象周围 2m 内随机取一个偏移（世界坐标，例如"西南 2m"），此后始终前往「对象当前位置 + 该偏移」，对象移动时自动跟着挪，多个人机不会挤在同一格。
  自然转换：对象死亡/离线 → 搜索；对象周围 15m 内出现敌人 → 护送战斗。

护送战斗（被护送对象、敌人）
  行为与策略：见「战斗策略」"护送战斗"行。
  自然转换：敌人死亡 → 消费任务槽（有槽执行、无槽回护送）；敌人离开对象 22.5m → 护送；生命 < 15% → 危险躲避（任务槽保留）。

危险躲避（威胁位置）
  行为：朝背离威胁位置的方向退 20m，期间不放任何技能。
  自然转换：退到 20m 外 或 持续 4s → 消费任务槽：有槽执行、无槽回搜索。
  说明：躲避期间收到任务消息只入槽；解除信号可立即终止躲避并清槽。

危险清除（危险锚点：静态点 / 发送者位置快照）
  定位：按「危险警告」过去搜寻，没有交战，因此可被任何任务消息立即打断。
  行为：朝危险锚点移动；到达后在 15m 范围内索敌。
  计时：进入本状态即开始计时，30s 内一直没在范围内发现敌人 → 回搜索。
  自然转换：范围内发现敌人 → 追击（返回态 = 危险清除）→ 进攻击距离转危险清除战斗。
  收到消息：解除 → 搜索；危险警告 → 按距离/血量重新判定清除或躲避；护送 / 集结 / 进攻 / 争夺中立 → 立即切换（不入槽）。

危险清除战斗（危险点、敌人）
  行为与策略：见「战斗策略」"危险清除战斗"行。
  自然转换：敌人死亡 → 消费任务槽（有槽执行、无槽回危险清除继续搜寻）；敌人离开危险点 22.5m → 危险清除；生命 < 30% → 危险躲避（任务槽保留）。

前往集结（集结锚点）
  行为：朝集结锚点移动。
  自然转换：与锚点距离 ≤ 5m → 集结等待。

集结等待（集结锚点）
  行为：在锚点附近待机，与锚点距离超过 10m 就回去（动态锚点即跟着发送者移动）。
  自然转换：10m 内发现敌人 → 自己 + 25m 内的友方人机一起进入集结守卫（目标 = 该敌人）。

集结守卫（集结锚点、敌人）
  行为与策略：见「战斗策略」"集结守卫"行。
  自然转换：生命 < 20% → 前往集结（任务槽保留）；敌人死亡 或 敌人离开集结点 15m → 消费任务槽（有槽执行、无槽回集结等待）。

协同进攻（进攻锚点）
  行为：朝进攻锚点移动；到达后找最近的敌人，找到就追击（返回态 = 协同进攻）。
  自然转换：
    静态锚点：到达且范围内无敌 → 转入搜索。
    动态锚点：始终跟随发送者，原地待机也不脱离；发送者死亡/离线 → 搜索。

协同进攻战斗（进攻锚点、敌人）
  行为与策略：见「战斗策略」"协同进攻战斗"行。
  自然转换：敌人死亡 → 消费任务槽（有槽执行、无槽回协同进攻）；敌人超出攻击距离但仍在 25m 内 → 追击（返回态 = 协同进攻，槽保留）；超出 25m → 协同进攻；生命 < 30% → 危险躲避（任务槽保留）。

【目标不可达】
寻路求出的方向为零、或长时间没有实际位移（例如目标在墙外/平台上）→ 原地停留 2s，然后按当前状态重新选点（搜索重取游荡点、任务态重算锚点方向），避免围着障碍物原地抽搐。

解除信号：任何状态立即生效，清空任务槽 + 终止当前状态 + 回搜索。
危险警告：与危险位置距离 ≤ 30m 且生命 > 70% → 危险清除；其余 → 危险躲避。危险躲避进行中忽略新的危险警告。
护送/集结/争夺中立：后到覆盖；落在「战斗态与危险躲避」里只入槽，其余状态立即切换。
进攻(2)：在「前往集结 / 集结等待」立即切换为协同进攻；在战斗态与危险躲避里只入槽、脱战后执行；其余状态忽略——有敌人时人机自己会打，没敌人时也没有"进攻"的目标。
争夺中立：只在场上存在中立单位时有效，否则消息作废、保持原状态。
「请求上报各自状况」：全状态即时响应，回一条携带自身位置的「上报状况」，不改变行为、不打断动作、不重置任务。
自己发的消息一律忽略，不进入矩阵。

【发送端交互（客户端）】
按 1~8：面板收起时 → 展开快捷消息面板；面板展开时 → 发送对应消息并收起面板。
位置参数：按下数字键的瞬间若同时按住 J（空手攻击键）→ 取相机瞄准的中心点（屏幕中心射线与地面的交点）作为 targetPosition 发送；否则一律按"不携带位置"发送。
发送频率：同一玩家两条消息之间至少间隔 1s，面板内连按只发一条（防止刷屏把所有人的任务槽刷掉）。
